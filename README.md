# Contributing

Contributions are welcome.

Good contribution areas:

- Scenario design
- Rule balancing
- Unit profiles
- SAM / radar profiles
- Better ASCII map templates
- Snapshot validation tools
- Example playthroughs
- UI prototypes
- Documentation improvements

## Style principles

Please preserve the core design:

- Chat-native play
- Fog of war
- Snapshot as source of truth
- Calculation Stack for key results
- Fixed values from profile tables
- Custom strategy confirmation before execution
